# История изменений

## Сентябрь 2026

Скрипты не обновлялись с 2020 года, и часть из них перестала работать.

- В `start.sh` лежали флаги `-d64`, `AggressiveOpts`, `UseFastAccessorMethods`
  и `UseGCOverheadLimit`. Их убрали из JVM еще в Java 8-12, на Java 25 сервер
  с ними не стартует. Заменены на флаги Aikar с выбором параметров G1 по размеру кучи.
- `newLogic/updater.sh` ходил в `papermc.io/api/v1`, которого больше нет.
  Сейчас `fill.papermc.io/v3`, с проверкой sha256.
- В `newLogic/start.sh` было три ошибки: опечатка `lof` вместо `log` (третий аргумент
  не проверялся), `${@: -1}` вместо среза (до java доезжал только последний флаг),
  и сломанный порядок аргументов в строке запуска java.
- `backup.sh` снимал архив мира на живую, без `save-off`.
- `mcstart.sh` и `restart.sh` работали через screen с захардкоженными именами серверов.
- `ms.sh` переключал версии копированием папок туда-обратно.

Секреты вынесены в отдельные конфиги. Токен бота в теле скрипта уезжает в git,
в бэкап и в скриншот на форуме, а замечают это обычно поздно.
